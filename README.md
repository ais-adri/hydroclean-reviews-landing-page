# HydroClean — Testimoni Keluarga

Landing page testimoni HydroClean Indonesia. Data ulasan Google Maps dan reels Instagram
di-update harian oleh script `scripts/update.py` (dijalankan via cron Hermes).

- `index.html` — halaman utama (faux-embed Google Maps panel + IG reels grid)
- `data/google.json` — 30 ulasan Google terbaru (5★)
- `data/reels.json` — semua reels repost @hydroclean.id
- `assets/` — thumbnail reels
